# EcoAPI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el backend Spring Boot seguro y persistente del caso EcoRecicla, ejecutable junto con PostgreSQL mediante un solo comando.

**Architecture:** Controladores REST delgados delegan en servicios transaccionales; servicios aplican RN-01 a RN-04 y consultan repositorios JPA. Spring Security valida JWT y authorities por privilegio. Flyway es la única autoridad del esquema y semillas.

**Tech Stack:** Kotlin 2.4.10, Java 21, Spring Boot 4.0.7, Maven, PostgreSQL 17, Flyway, Spring Security, JJWT 0.12.6, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-28-ecoapi-design.md`

**Master tracker:** `../../../../tasks/todo.md`; always read `../../../../tasks/handoff.md` before resuming.

## Global Constraints

- Base de paquete: `pe.upeu.ecorecicla`.
- Todas las rutas protegidas viven bajo `/api/v1`; solo `POST /api/v1/auth/login` es pública.
- La zona de negocio es `America/Lima`; instantes persistidos en UTC.
- Contraseñas BCrypt; secreto JWT solo desde entorno; token de 3600 segundos.
- PostgreSQL y backend levantan con `docker compose up --build`.
- Errores usan exactamente `timestamp`, `status`, `error`, `message`, `path`, `validationErrors`.
- Ninguna regla de negocio o comparación de rol vive en controladores.

## Review Focus

- Token ausente, alterado o vencido produce 401 y nunca stack trace: Task 3.
- Operario corrigiendo pesaje ajeno o fuera del día produce 403: Task 6.
- Peso neto cero/negativo produce 400 asociado al campo: Task 5.
- Cierre con puntos sin pesaje ni omisión produce 409 con cantidad: Task 7.
- Anulación es lógica, conserva fila y devuelve 204 sin cuerpo: Task 6.
